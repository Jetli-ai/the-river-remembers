# The River Remembers

An original, feature-length AI drama package adapted from the short-form Realistic Mini Dramas playbook.

## Project

- **Format:** feature-length AI-assisted drama
- **Target runtime:** 47:21, matching the linked reference film’s player runtime
- **Frame:** landscape 16:9
- **Delivery master:** UHD 4K, 3840 × 2160, 24 fps
- **Genre and look:** cinematic royal-family melodrama with grounded West African-inspired settings, vivid faces, warm natural color, and polished, legible compositions
- **Story:** fully original. The reference link supplies a length and a broad melodramatic register; its characters, premise, scenes, and dialogue are not reused.

## Story in one sentence

When a drought exposes a river diversion that the palace buried for decades, a returning engineer and a crown prince must choose between preserving a comforting lie and sharing the truth with the people who will bear its cost.

## Evergreen idea

A title can command a room; only truth can earn its trust. Love grows when people stop using one another as symbols and begin taking responsibility side by side.

## Reference and adaptation note

The linked YouTube page identifies the film as “The Prince Pretended to Be Blind to Find True Love | Full Movie” and describes a royal romance. Its player reports 47:21. The observed quality menu showed Auto (480p); the source’s maximum uploaded resolution could not be verified. This project therefore uses the runtime as a match and UHD 4K as the explicitly requested target, not as a claim about the source file.

The source GitHub playbook is a short-form workflow built around vertical 9:16 clips, roughly 45-second stories, and Full HD export. This package rewrites those production assumptions for a single landscape feature. It is a production-ready story blueprint, not a rendered movie file.
